# センチュリー21 ハウスマーケット リフォーム部門サイト（初版）

GitHub Pagesで公開できる、HTML・CSS・JavaScriptのみの静的サイトです。

## 公開前に差し替える情報

- お問い合わせフォームURL（フォームを設置する場合）
- 正式な対応エリア
- 正式なサービス方針・業務フロー
- 掲載許可を得た施工事例
- 公式ロゴ・ブランド表記ルール

未確認の施工件数・資格・実績は掲載していません。ページ内の「確認中」「仮掲載」「準備中」の箇所は、正式情報の確認後に更新してください。

## GitHub Pagesでの公開

リポジトリの `Settings` → `Pages` で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/(root)` に設定すると公開できます。

## ファイル構成

- `index.html` — ページ本文
- `styles.css` — デザイン・レスポンシブ対応
- `script.js` — スマートフォン用メニュー
